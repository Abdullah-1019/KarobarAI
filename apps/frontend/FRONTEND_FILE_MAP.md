# KarobarAI Frontend — File Map

Every file under `apps/frontend/src` (plus root config files), grouped by folder, with a one-line description of what it does.

## Entry / Config

| File | Description |
|---|---|
| `index.html` | HTML shell loading fonts, PWA icon, and the main.tsx module entry. |
| `vite.config.ts` | Vite build config with React plugin and PWA manifest/icon setup. |
| `src/main.tsx` | App entry point; mounts AppProviders into the DOM root under StrictMode. |
| `src/vite-env.d.ts` | TypeScript ambient declarations for Vite client types and env variables. |

## `src/app/` — App shell, routing, providers

| File | Description |
|---|---|
| `AppProviders.tsx` | Root provider composing QueryClient, AntD theme/direction, router, and boot-time session restore via refresh()+me(). |
| `HealthIndicator.tsx` | Dev-only fixed badge polling GET /health to show API connectivity status. |
| `ProtectedRoute.tsx` | Route guard redirecting to /login or showing "not authorised" based on auth status and allowed roles. |
| `global.css` | Global CSS design tokens (colors, spacing, type, shadows) plus shell/auth/animation styles for the whole app. |
| `i18n.ts` | Initializes i18next with EN/UR resource bundles and persists/reads the chosen language from localStorage. |
| `index.ts` | Barrel export re-exporting AppProviders. |
| `router.tsx` | Defines the app's React Router route tree, nesting layouts and RBAC-protected route groups per role. |
| `theme.ts` | AntD ConfigProvider light/dark theme token definitions ported from the UI/UX spec. |
